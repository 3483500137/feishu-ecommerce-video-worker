# 飞书账号复刻工具使用教程

本教程对应当前 Base 和本机 Worker。日常运营人员可直接从“人设管理”开始；首次部署或更换电脑时，请先完成“接入API”和本机计划任务配置。

> 这是自托管工作流。获得 Base 链接并不等于能够生成内容：任务实际使用运行 Worker 那台电脑上的模型密钥、浏览器登录态和计算环境。不要多人共用生产 Base 和同一套密钥。

## 一、先认识左侧模块

| 模块 | 什么时候使用 | 自动结果 |
|---|---|---|
| 接入API | 首次部署、添加模型、换密钥 | 验证状态、密钥尾号、最近验证时间 |
| 人设管理 | 创建人物设定与人物图片 | 人设文字、人物形象、任务状态 |
| 小云雀内容管理 | 用小云雀/Seedance 复刻参考视频 | 最终视频链接与附件 |
| 中转站生成内容管理 | 文生、图生、首尾帧或参考视频生成 | 提示词、外部任务 ID、最终视频 |
| LTX内容管理 | 按参考视频分段生成并合成 | 分段任务、最终视频与原音轨 |
| 平台账号 | 绑定当前 Chrome 登录账号 | MultiPost 账号 ID、昵称和登录状态 |
| 平台发布 | 生成文案并在确认后发布 | 发布状态、实际发布时间和作品链接 |

日常最常用路径是：配置模型 → 生成人设 → 选择一种视频生成表 → 检查成片 → 可选平台发布。

## 二、首次部署或更换电脑

从 GitHub 导入的 `.base` 模板只包含表结构、仪表盘和 3 个禁用的自动化占位项。人设、视频和发布任务由本机 Worker 与 Windows 计划任务接管；不要启用占位自动化，也不要把其他人的生产 Base token 填入自己的配置。

### 2.1 安装本机程序

在项目目录完成 Node.js 依赖、飞书 CLI、FFmpeg 和 yt-dlp 安装，复制 `config.example.json` 为 `config.json`，填写 Base token、表 ID 和附件字段 ID。

运行：

```powershell
npm run doctor
npm test
powershell -ExecutionPolicy Bypass -File .\scripts\install-multipost-account-server.ps1
powershell -ExecutionPolicy Bypass -File .\scripts\install-scheduled-task.ps1
```

正常情况下会看到：

- `FeishuAccountClonerWorker`
- `FeishuAccountClonerWorkerController`
- `FeishuAccountClonerMultiPost`

使用 LTX 首尾帧时，还需要安装 `FeishuAccountClonerMediaRelay`。

### 2.2 配置“接入API”

“接入API”采用一模型一行，不要把多个模型写在同一行。

1. 填写“接入名称”“服务商类型”“API协议”“接口地址”“模型名称”和“模型ID”。
2. 选择“模型能力”：文本、视觉分析、图像生成或视频生成。
3. 点击“配置接入”，在打开的本机页面输入密钥。
4. 点击验证。验证成功后，“验证状态”变为“有效”，表格只显示密钥尾号。
5. 按用途设置“是否默认”：人设文本、人物形象、提示词、视频生成或发布文案。

同一用途最多保留一个默认模型。业务记录里明确选择的模型优先于默认模型；模型停用、能力不匹配、存在多个默认或本机没有密钥时，任务会在收费请求前停止并写入失败原因。

密钥只保存在当前 Windows 用户的 DPAPI 加密凭据库。复制 Base 或复制 `runtime/credentials.json` 到另一台电脑都不能直接使用，换机后必须重新点击“配置接入”导入。

## 三、生成人设

1. 打开“人设管理”，新增一行。
2. 填写“手机编号”和“输入人设要求”，按需选择“人设类型”。
3. 可上传“参考图片”。参考图片用于锁定同一张脸，不用于照搬背景、服装和姿势。
4. 选择“人设文本模型”和“人物形象模型”；留空时使用“接入API”中对应用途的唯一默认模型。
5. 将“是否立刻生成人设”设为“是”。
6. 等待“人设生成状态”变为“已完成”，检查“人设”和“人物形象”。

人物形象应为真实摄影效果。若结果不符合要求，修改“输入人设要求”后再次明确触发；主动重试可能产生新的模型费用。

“人设编号”为展示编号，线程 ID、运行 ID、内部链接和原始结果字段由程序维护，不要手工修改。

## 四、选择视频生成路径

三张视频表互不替代。小云雀适合已有参考视频的快速人物替换；中转站适合灵活调用兼容 Videos 接口；LTX 适合按参考视频分段近似复刻。

### 4.1 小云雀内容管理

1. 选择一条已经有人物形象的人设。
2. 填写“视频提示词”，粘贴“参考视频链接”或上传“参考视频文件”。
3. 选择“文本/分析模型”和“视频生成模型”。旧“模型选用”字段仅用于历史兼容。
4. 将“是否立刻生成视频”设为“是”。
5. 等待“生成状态”变为“已完成”，检查“最终视频”和“最终视频文件”。

系统会尽量保持参考视频动作、节奏、声音和时长，只把人物替换为所选人设，并要求 9:16 画面铺满。参考文件通常比短链接稳定。

### 4.2 中转站生成内容管理

“生成方式”支持文生视频、图生视频、首尾帧和参考视频生成。

1. 选择人设、文本/分析模型和视频生成模型。
2. 填写“输入内容要求”，并按生成方式上传参考图片、尾帧图片或参考视频。
3. “生成视频提示词”选择“是”可首次生成，选择“重新生成”会覆盖旧提示词；选择“否”时可手工填写提示词。
4. 需要提示词完成后立即提交视频时，将“是否立刻生成视频”设为“是”。
5. 失败后需要重新提交时，使用“重试生成”，不要手工清除外部任务 ID。

获得外部任务 ID 后，后续扫描只轮询原任务，不会重复提交。参考视频生成固定按 9:16 处理，并优先使用检测到的真实参考时长。随机种子可留空，需要复现时再填写整数。

### 4.3 LTX内容管理

1. 选择人设、分镜分析模型和视频生成模型。
2. 填写可下载的“参考视频链接”和可选“视频提示词”。
3. 旧“模型选用”可选择 `LTX 2.3 单帧` 或 `LTX 2.3 首尾帧`。
4. 将“是否立刻生成视频”设为“是”。

Worker 会检测参考时长，按约 5 秒动态分段，提取边界帧，通过临时 HTTPS 中继提交任务，再用 FFmpeg 合并片段、裁切到参考时长并复用参考音轨。该流程属于近似复刻，不保证人物细节、动作和镜头完全一致。

## 五、绑定账号与平台发布

### 5.1 绑定平台账号

1. 在 Chrome 中登录目标创作者平台。
2. 确认已加载项目目录中的 MultiPost 扩展。
3. 在“平台账号”选择平台并点击“获取MultiPost”。
4. 首次访问时允许扩展信任 `127.0.0.1`。
5. 确认账号昵称、MultiPost 账号 ID 和登录状态正确。

本地服务不保存平台密码、Cookie 或验证码，但会使用当前 Chrome 配置文件的登录态。

### 5.2 发布内容

1. 在“平台发布”关联内容和平台账号。
2. 选择“发布文案模型”，生成标题、文案和标签。
3. 人工检查最终视频、账号、标题、文案、标签和计划时间。
4. 只有确认无误后，才把“确认发布”设为“是”。

只有“文案生成状态=已完成、发布状态=待确认、确认发布=是”的记录才会提交。已有 MultiPost 任务 ID 或幂等键时不会重复提交；当前 Chrome 账号必须与飞书绑定账号一致。

验证码、扫码登录和平台风控必须人工处理。不要通过反复切换确认开关绕过失败原因。

## 六、状态、恢复与重试

| 状态 | 含义 | 正确处理 |
|---|---|---|
| 待生成 | 输入已准备，尚未提交 | 等待下一轮扫描 |
| 生成中 | 已提交或正在轮询 | 保持电脑和网络在线，不要重复触发 |
| 已完成 | 真实产物已回填 | 人工检查结果 |
| 失败 | 配置、素材、接口或回填失败 | 先看失败原因，修正后使用明确重试项 |

线程 ID、运行 ID、外部任务 ID、模型快照、幂等键和内部素材键用于恢复任务。手工清除这些字段可能导致重复收费、重复发布或无法续查。

若任务长时间停在“生成中”：

1. 检查电脑是否休眠、断网或计划任务被停用。
2. 运行 `npm run doctor`。
3. 检查 `logs/worker.log` 和 `logs/worker-launcher.log`。
4. 有外部任务 ID 时先恢复 Worker，让系统续查原任务。

## 七、安全边界

- API Key 只能通过“配置接入”写入本机 DPAPI 凭据库，不要写进 Base、教程、README 或聊天。
- 正式接口地址应使用 HTTPS。
- 只处理已获授权的人脸、视频、声音和账号。
- 生成和重试可能产生费用；触发前先检查输入与模型。
- 不要把生产 Base 链接、浏览器用户目录或 `runtime/credentials.json` 公开分享。
