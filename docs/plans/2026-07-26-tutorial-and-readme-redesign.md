# 教程与 README 重构设计

## 目标

让首次部署者能够独立完成安装、模型接入和 Worker 启动，让日常运营人员能够按真实表结构完成人设、三类视频任务和平台发布，同时保证公开文档不泄露生产 Base 标识或密钥。

## 信息架构

README 面向开源部署者，按“项目边界 → 当前模块 → 部署 → 模型配置 → 日常使用 → 安全与开发”组织。Base 内嵌教程面向已经进入工作台的使用者，按“模块导航 → 首次部署 → 生成人设 → 三种视频路径 → 发布 → 恢复与安全”组织。

两份文档共享相同事实，但不机械复制：README 提供克隆、导入模板和本机命令；Base 教程重点解释字段、触发开关、状态和重试规则。`docs/feishu-base-tutorial.md` 作为 Base 教程的可审查源文件。

## 事实来源

- 表名和字段名来自当前生产 Base 的实际 `base +base-block-list` 与 `base +field-list` 返回。
- 任务名、命令和依赖来自合并后的脚本与 `package.json`。
- 模型路由、安全边界和重试行为来自当前 Worker、provider adapters、credential store 与测试。
- GitHub 分支状态以 GitHub API 和远端提交树比较为准。

## 发布与验证

在隔离 worktree 中合并公开 `main`、本地模型路由提交和当前未提交功能。完成测试、PowerShell 语法、敏感信息、模板导入和文档回读验证后更新 `main`。旧远端功能分支只有在确认文件树与 `main` 一致后删除，最终远端只保留 `main`。
