# 可配置多模型接入与中转站生成设计

## 目标

在不按模型拆分数据表的前提下，让每位部署者在自己独立的一套飞书多维表和本地 Worker 中导入小云雀、Kimi/其他兼容模型及中转站配置，并在“人设管理”“小云雀内容管理”“中转站生成内容管理”“LTX内容管理”和“平台发布”中按任务阶段选择实际模型。

每位部署者拥有一套独立多维表和一个本地 Worker。系统不实现多人共用同一多维表时的租户隔离。

## 核心决策

- 只保留一张“接入API”表，不新增模型表；一条记录代表一个可选择的模型。
- 文本/分析模型与图像/视频生成模型分别选择，但不为不同模型创建内容表。
- API 密钥不以明文写入飞书、`config.json`、日志或任务记录。
- 密钥通过本地配置页导入，使用 Windows DPAPI 加密并绑定当前 Windows 用户。
- Worker 根据关联的“接入API”记录完成能力验证、凭据解析和协议适配。
- 已明确选择模型时绝不静默切换；只有字段留空时才使用相应用途的默认模型。
- 现有三张内容表、旧字段和旧环境变量在迁移期保持兼容。

## 数据模型

### 接入API（由 `access_api_table_id` 配置）

一条记录代表一个模型，字段如下：

- 接入编号：自动编号，格式 `API-0001`。
- 接入名称：部署者可读名称。
- 服务商类型：小云雀、Kimi、OpenAI兼容、中转站、其他。
- API协议：Chat Completions、Videos、XYQ Skill。
- 接口地址：不含密钥的 Base URL。
- 模型名称：飞书显示名称。
- 模型ID：请求中实际使用的 `model` 值。
- 模型能力：文本、视觉分析、图像生成、视频生成。
- 本机密钥别名：指向 DPAPI 凭据库的稳定别名。
- 配置接入：打开 `http://127.0.0.1:17386/api-config` 的公式链接。
- 是否默认：人设文本、人物形象、提示词、视频生成、发布文案。
- 是否启用：是、否。
- 验证状态：未配置、待验证、有效、已失效。
- 最近验证时间、失败原因：由本地服务回填。

### 业务表关联

- 人设管理：人设文本模型、人物形象模型。
- 小云雀内容管理：文本/分析模型、视频生成模型。
- 中转站生成内容管理：文本/分析模型、视频生成模型。
- LTX内容管理：分镜分析模型、视频生成模型。
- 平台发布：发布文案模型。

所有字段关联“接入API”。旧“模型选用”字段先保留；新关联字段为空时可以读取旧值完成兼容映射。

### 中转站生成内容管理（由 `relay_content_table_id` 配置）

- 内容流水号：`RT-00001`。
- 人设、输入内容要求、参考图片、参考视频、尾帧图片。
- 文本/分析模型、视频生成模型、视频提示词。
- 生成方式：文生视频、图生视频、首尾帧、参考视频生成。
- 视频时长、画面比例、随机种子；画面比例默认 `9:16`。
- 是否立刻生成视频、重试生成。
- 生成状态：待生成提示词、生成提示词中、待生成视频、生成中、已完成、失败、需要配置。
- 实际文本模型、实际视频模型：任务开始时写入的内部快照。
- 外部任务ID、最终视频、最终视频链接、提交时间、完成时间、失败原因。

## 本地凭据与配置页

现有本地服务继续监听 `127.0.0.1:17386`，增加 `/api-config` 页面与 POST 接口。

- 页面接收 API Key/Access Key，密钥只通过请求体进入本地进程。
- DPAPI 密文保存在 `runtime/credentials.json`；每个条目保存密文、脱敏尾号和更新时间。
- 飞书只保存本机密钥别名及脱敏后的验证结果。
- 页面支持验证单条模型；OpenAI 兼容接口可以读取 `/v1/models`，勾选后在同一“接入API”表创建一模型一行的记录。
- 保存后不允许查看原密钥，只允许替换或明确删除。
- 本地服务校验 Host、Origin、请求方法和同源 CSRF 令牌，所有日志对 Authorization 和密钥值脱敏。

## 统一路由

运行链路为：

`业务记录 -> 接入API记录 -> 能力验证 -> 本机密钥别名 -> 协议适配器 -> 模型接口`

首批协议适配器：

- Chat Completions：Kimi及其他 OpenAI 兼容文本/视觉模型。
- Videos：NewAPI/OpenAI 兼容中转站视频模型和现有 LTX 调用。
- XYQ Skill：小云雀图片与视频生成。

Worker 启动时不再强制要求同时存在 `KIMI_API_KEY` 与 `XYQ_ACCESS_KEY`。只有任务使用某项接入时才解析相应凭据。旧环境变量可在找不到本机密钥别名时作为迁移期后备。

## 状态与故障处理

- 未导入密钥、接入未启用、能力不匹配：任务设为“需要配置”，不发起收费请求。
- 401/403：接入验证状态设为“已失效”。
- 429和临时5xx：提交前或幂等安全的读取请求指数退避，最多三次。
- 一旦取得外部任务ID，后续只恢复轮询，不重新提交。
- 下载或飞书附件上传失败时保留生成结果链接，只重试回填。
- 受控重试产生新的任务尝试，触发字段立即复位，避免 Worker 循环扣费。
- 任务启动后保存模型快照，接入配置的后续修改不改变运行中任务。

## 迁移

1. 新增表字段，不删除旧字段。
2. 创建当前 Kimi、小云雀和 NewAPI/LTX 的接入记录。
3. 将环境变量凭据一次性导入 DPAPI 凭据库。
4. 依次切换人设、小云雀内容、LTX内容、中转站内容和平台发布。
5. 验证历史任务和新任务后隐藏旧字段；迁移期继续接受旧配置。

## 验收

- 部署者可以从本地配置页导入并验证自己的三类服务配置。
- 飞书、日志与 `config.json` 中不存在 API 密钥明文。
- 各业务表能分别选择文本/分析模型和图像/视频模型。
- 中转站任务默认 `9:16`，成功与失败均回填完整状态。
- 未配置一个供应商不会阻止其他供应商任务。
- 实际模型与飞书选择一致，重启后恢复轮询且不重复提交。
- 现有表、历史记录、MultiPost 发布和旧配置保持兼容。
