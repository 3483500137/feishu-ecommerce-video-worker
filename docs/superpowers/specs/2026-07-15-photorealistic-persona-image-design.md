# 真人摄影人物形象设计

## 目标

小云雀生成人物形象时，输出必须呈现真实相机拍摄的成年女性照片效果，不得生成 2D 或 CG 风格形象。

## 视觉约束

- 保留 Kimi 生成人设、清纯气质、20 至 30 岁成年女性及用户指定服装。
- 使用真实相机拍摄效果、真实女性、自然皮肤纹理、真实五官比例和自然人体结构。
- 画面为单人全身人物照片，不出现其他人物。
- 明确禁止 2D、动漫、插画、卡通、二次元、绘画、3D CG、游戏建模、数字人、塑料皮肤和明显渲染质感。
- “真人摄影”只约束表现形式，不改写人设内容或用户输入要求。

## 实现

- 将人物形象任务消息提取为 `buildPersonaImagePrompt` 纯函数。
- `processPersona` 使用该函数构造小云雀消息，继续沿用现有提交、轮询、附件下载与飞书回填逻辑。
- 不增加生成后图像识别、自动重做、固定参考脸或新的第三方服务。

## 测试

- 任务消息必须包含真人摄影、真实成年女性、自然皮肤纹理与真实五官比例。
- 任务消息必须明确排除 2D、动漫、插画、3D CG、游戏建模和数字人。
- 任务消息必须继续包含人设正文、用户要求、年龄、清纯、指定服装、单人全身及无其他人物约束。
- 现有视频、时长、链接回退和产物选择测试必须继续通过。

## 生效范围

修改仅作用于更新后新触发或重新触发的人物形象生成任务；不会自动重新生成现有的人物形象。
