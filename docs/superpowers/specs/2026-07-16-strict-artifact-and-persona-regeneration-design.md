# 严格产物选择与主动人设重生成设计

## 目标

修复以下生产故障：

1. 主动选择“是否立刻生成人设=是”时，旧内部图片 URL 导致工作器只恢复旧附件、没有真正重新生成。
2. 小云雀没有生成视频产物时，工作器把任务提示中的参考视频链接误填为“最终视频”。
3. 小云雀生成多个视频片段和最终合成视频时，工作器选择第一个片段而不是最后合成成片。

## 人设任务分派

- “是否立刻生成人设”为“是”时，直接进入 `processPersona`，必须重新调用 Kimi 和小云雀。
- 只有未主动触发且“人物形象”附件缺失时，才允许 `backfillPersonaAttachment` 使用旧内部图片 URL 恢复附件。
- 主动重生成开始后，现有逻辑继续把开关改为“否”，避免每分钟重复生成。
- 不改动真人摄影人物形象提示、附件替换和飞书回填格式。

## 小云雀产物选择

- 只检查 `runData.entry_list` 中带有 `artifact` 的产物节点。
- 图片只接受 artifact 内容中的 `biz/x_data_image`；视频只接受 `biz/x_data_video`。
- 按产物出现顺序从后向前选择，因此多片段任务优先返回最后生成的合成成片。
- 不扫描用户提示、普通助手消息、工具请求或上传的参考素材 URL。
- 小云雀状态为完成但没有对应类型 artifact 时，返回空结果，由现有完成逻辑标记失败并写入“任务完成但未找到视频/图片结果”。
- 视频失败时保持“最终视频”为空，不得回填参考视频链接。

## 回归测试

- 主动触发人设时，即使存在旧内部 URL，也必须选择重新生成而不是附件恢复。
- 非主动触发且附件缺失时，仍允许附件恢复。
- 产物选择器忽略提示中的抖音链接。
- 只有片段与合成视频时，必须选择最后一个视频 artifact。
- 没有视频 artifact 时必须返回空结果。
- 图片 artifact 选择继续正常工作。
- 现有真人摄影提示、时长约束、链接回退和辅助函数测试继续通过。

## 修复后一次性重试

- 重新执行 PS-0002 一次，并下载新附件进行视觉核验；必须是像真实相机拍摄的真人女性照片，不得是 2D 插画或 CG 数字人。
- 重新执行 CT-00005 一次；只有真实视频 artifact 才回填“最终视频”。
- 若抖音链接再次解析失败，CT-00005 标记失败并记录明确原因，不再自动重试。

## 生效与运行

- 修改期间保持 `FeishuEcommerceVideoWorker` 暂停。
- 代码测试通过后设置两条记录的触发开关并恢复计划任务。
- 验收完成后保持计划任务启用。
