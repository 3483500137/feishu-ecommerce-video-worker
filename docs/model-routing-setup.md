# 每位部署者配置模型与中转站

本工作流采用“一位部署者一套飞书多维表 + 一个本地 Worker”。模型不拆表；`接入API` 中一行代表一个可选择的模型。飞书保存服务商、接口、模型和验证状态，API Key/Access Key 只保存在部署者电脑的 Windows DPAPI 加密凭据库中。

## 1. 初始化表结构

在工作目录执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\configure-model-routing-base.ps1
```

脚本只补字段，不删除历史字段或历史记录。中转站内容默认画面比例为 `9:16`。

## 2. 启动本地配置服务

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\run-multipost-account-server.ps1
```

也可以安装登录后自动运行的计划任务：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\install-multipost-account-server.ps1
```

该服务只监听 `127.0.0.1:17386`。如果服务未启动，飞书里的“配置接入”和“获取MultiPost”链接都无法打开。

## 3. 导入每个模型的密钥

1. 在飞书打开`接入API`。
2. 一行填写一个模型：服务商类型、API协议、接口地址、模型名称、模型ID和模型能力。
3. 点击该行的“配置接入”。
4. 在本地页面输入密钥并保存，然后点击“验证并读取模型”。
5. OpenAI 兼容接口可以勾选模型并批量导入；系统仍在同一张`接入API`表中按“一模型一行”创建记录。
6. 在“是否默认”中按用途最多设置一个默认模型，或在每条业务记录里明确选择模型。

密钥保存于 `runtime/credentials.json`，文件内只有 DPAPI 密文、尾号和更新时间。它与当前 Windows 用户及电脑绑定，复制到另一台电脑不能解密；换机后必须重新导入。页面不回显已保存密钥，只允许替换或删除。

旧的 `KIMI_API_KEY`、`XYQ_ACCESS_KEY`、`NEWAPI_API_KEY` 仍可作为迁移期后备。Worker 首次发现对应`接入API`记录且本机别名尚无凭据时，会一次性导入 DPAPI。之后可以删除用户环境变量。

## 4. 在业务表选择模型

- `人设管理`：人设文本模型、人物形象模型。
- `小云雀内容管理`：文本/分析模型、视频生成模型。
- `中转站生成内容管理`：文本/分析模型、视频生成选用。
- `LTX内容管理`：分镜分析模型、视频生成模型。
- `平台发布`：发布文案模型。

显式选择优先于默认模型。空白时按“是否默认”的用途解析；没有默认、存在多个默认、模型已停用、能力不匹配或本机未导入密钥时，任务会停止并回填配置错误，不会自动切换到其他模型，也不会发起收费请求。

旧的“模型选用”字段暂时保留。新关联字段为空时，Worker 会按旧模型名称匹配`接入API`记录；迁移完成后可隐藏旧字段，不要直接删除历史数据。

## 5. 中转站内容流程

1. 选择人设、文本/分析模型、视频生成选用和生成方式。
2. 填写输入内容要求；画面比例默认 `9:16`。选择“参考视频生成”时会强制使用 `9:16` 竖屏复刻，不受画面比例字段改成横版的影响。
3. 将“生成视频提示词”设为“是”或“重新生成”。“是”用于首次生成；“重新生成”会覆盖当前视频提示词重新生成；“否”表示跳过自动提示词，可手动填写。
4. Worker 会根据输入要求和参考图/视频/链接生成符合复刻要求的视频提示词，生成后可人工修改。
5. 如需提示词完成后马上提交视频任务，将“是否立刻生成视频”设为“是”；失败后需要重新生成视频时，将同一字段改为“重试生成”。
6. 获得外部任务ID后，后续扫描只轮询该任务，不会重复提交。
7. 成功后回填最终视频链接；失败后回填失败原因。

支持文生视频、图生视频、首尾帧和参考视频生成。参考视频生成会以参考视频为最高优先级：每次提交前都会读取参考视频并用检测到的真实时长覆盖/校准“视频时长”，最终视频要求与参考视频时长一致，误差不超过 1 秒。选择“是否立刻生成视频=重试生成”时，Worker 先消耗并复位该触发项，清除旧任务ID，再由下一轮创建一次新尝试。

“随机种子”可以留空。需要复现或微调某次生成效果时，再填写一个整数，例如 `1`、`42`、`20260722`；同一模型、同一提示词和相近参数下，相同随机种子会尽量让画面结果更接近，换一个数字则会增加随机变化。

## 安全边界

- 401/403 会标记为需要重新配置；429和临时5xx只对安全的读取请求重试。
- 任务开始后保存模型快照，运行中的外部任务不会因飞书模型配置变更而切换模型。
- 中转站接口应使用 HTTPS。当前部署若仍使用 HTTP，密钥和内容可能以明文网络流量传输；在正式导入密钥前应先改为 HTTPS。
- 登录失效、二维码、验证码和平台风控仍需要在 MultiPost/浏览器人工处理。
